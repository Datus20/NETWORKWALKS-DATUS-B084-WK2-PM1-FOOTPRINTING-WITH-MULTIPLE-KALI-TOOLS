## 📌 Project Overview

This project focuses on using a kali tools **Footprinting about on target inorder to fetch/get available iformation about a target** using and Kali Linux.

The purpose of the lab is to use cybersecurity tools, for footprintinhg inorder to identify vulnerability, include who own a domain  register expiry, technologies running  website, who is hosting  adomain, Webapplication firewall,DNS Records, IP & mail services,

The lab is configured on a private virtual network so that additional machines can be added later and used as targets for authorized security testing.

---


## 🎯 Objectives

The main objectives of this project are to:

- To check Who own **domain**.
- Identify the Real **Ip Address**.
- Identifying **Hosting** Provider.
- Identifying **Web Technologies** used(*Website*).
- Check for it's **DNS & Mail** records.
- Whether its protected by a **WAF** Web Application firewall.

---

## 🛡️ Purpose of the Project

The Purpose of this project is to do Reconnaissance or Footprinting  Web security testing by using Kali tools  listed as below,such as:
- **Whois**
- **Whatweb**
- **Nslookup**
- **Curl**
- **Wafw00f**
- **Dnsrecon**
